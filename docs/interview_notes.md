# 面试讲解提纲

## 1. 项目解决什么问题？

这个项目主要解决第三方 API 数据格式不统一、人工同步效率低、入库过程缺少运行记录的问题。我用 Python 调用公开 API 获取数据，经过字段清洗、缺失值处理和日期格式标准化后写入 MySQL，同时设计了同步日志表记录每次任务的运行状态，最后用 FastAPI 提供查询接口，并用 Postman 做接口测试。

## 2. 怎么保证数据不重复？

在 `weather_daily` 表中设置了 `city + weather_date` 唯一索引，同一城市同一天只保留一条记录。写入时使用 upsert 逻辑，如果数据已经存在，就更新温度、降水量、风速和更新时间；如果不存在，就插入新记录。

## 3. 如果 API 请求失败怎么办？

代码中设置了请求超时时间和异常捕获。任务失败时会写入 `sync_log` 表，记录任务名称、开始时间、结束时间、同步条数、失败状态和错误信息，便于后续定位是网络问题、接口返回问题还是数据库写入问题。

## 4. 做了哪些数据清洗？

主要包括字段筛选、字段重命名、日期格式统一、数值类型转换、缺失日期过滤、重复记录去重，以及补充城市名称、经纬度、数据来源等字段。

## 5. 为什么适合 API 和数据库方向岗位？

这个项目覆盖了岗位中提到的 API 对接、JSON 解析、数据清洗、数据库入库、同步任务监控、接口文档维护和 Postman 测试等要求；同时我之前做过股票预测辅助系统，也涉及行情 API 采集、财经新闻数据采集、MySQL/MongoDB/Redis 存储和后端 RESTful API 封装。
